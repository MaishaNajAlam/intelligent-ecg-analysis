## 📌 Overview

The **Intelligent ECG Analysis Tool** is a production-grade, deep-learning-powered clinical decision support system designed to assist cardiologists and healthcare professionals in interpreting 12-lead electrocardiograms (ECGs).

Cardiovascular diseases (CVDs) remain the leading cause of global mortality (~17.9M deaths annually). While recording a 12-lead ECG is rapid and non-invasive, accurate clinical interpretation requires scarce cardiology expertise. This system bridges the diagnostic gap by providing:

1. **Signal-to-Diagnosis (Multi-Label Classification)**: Calibrated diagnostic predictions and confidence scores across 5 clinical superclasses (`NORM`, `MI`, `STTC`, `CD`, `HYP`).
2. **Signal-to-Report (Natural Language Generation)**: Automated, structured clinical narratives generated by an adapter-bridged sequence-to-sequence language model (`BART-base` + LoRA).
3. **Explainable AI (Saliency Mapping)**: Gradient-based temporal attribution overlaid on all 12 leads, highlighting exact waveform regions driving model decisions (e.g., ST elevation, pathological Q-waves, QRS widening).
4. **Clinical-Grade PDF Export**: Instant generation and interactive preview of hospital-style PDF reports featuring patient demographics, diagnostic summaries, confidence differentials, waveform tracings, and physician sign-off lines.
5. **Interactive Web Interface**: A responsive Gradio application supporting test-set browsing, custom 12-lead CSV uploads, and batch multi-record analysis.

## 🏗️ System Architecture

The pipeline implements a **dual-head multi-modal transformer architecture** anchored by a frozen self-supervised biomedical foundation encoder:

```
                    ┌──────────────────────────────────────────────────────────┐
                    │      Raw 12-Lead ECG Signal (10 sec @ 500 Hz)            │
                    │      Shape: (12 leads, 5000 samples)                     │
                    └─────────────────────────────┬────────────────────────────┘
                                                  │
                                                  ▼
                    ┌──────────────────────────────────────────────────────────┐
                    │   Signal Preprocessing (Per-lead Z-score / Bandpass)     │
                    │   Normalized Waveform (12, 5000)                         │
                    └─────────────────────────────┬────────────────────────────┘
                                                  │
                                                  ▼
                    ┌──────────────────────────────────────────────────────────┐
                    │            HuBERT-ECG Foundation Encoder                 │
                    │     (Frozen SSL 1D-CNN + 12-Layer Transformer)           │
                    │            Pre-trained on 9.1M ECGs                      │
                    └─────────────────────────────┬────────────────────────────┘
                                                  │
                                 Feature Tensor (L=249, d=768)
                                                  │
                         ┌────────────────────────┴────────────────────────┐
                         │                                                 │
                         ▼                                                 ▼
        ┌──────────────────────────────────┐             ┌──────────────────────────────────┐
        │    Mean Temporal Pooling         │             │    Feature Adapter (MLP)         │
        │    (L, 768) ──▶ (768,)           │             │    Linear(768,512) ──▶ GELU      │
        └────────────────┬─────────────────┘             │    ──▶ LayerNorm ──▶ Linear(768) │
                         │                               └────────────────┬─────────────────┘
                         ▼                                                │
        ┌──────────────────────────────────┐                              ▼
        │   Classifier Head (2-Layer MLP)  │             ┌──────────────────────────────────┐
        │   Linear(768, 256) ──▶ ReLU      │             │    BART-Base Decoder             │
        │   ──▶ Dropout(0.3) ──▶ Linear(5) │             │    (Pretrained Seq2Seq LM + LoRA)│
        └────────────────┬─────────────────┘             │    Cross-Attention over Adapter  │
                         │                               └────────────────┬─────────────────┘
                         ▼                                                │
        ┌──────────────────────────────────┐                              ▼
        │   Multi-Label Probabilities      │             ┌──────────────────────────────────┐
        │   Sigmoid: NORM, MI, STTC,       │             │   Autoregressive Text Generation │
        │            CD, HYP               │             │   Beam Search (width=4)          │
        └────────────────┬─────────────────┘             └────────────────┬─────────────────┘
                         │                                                │
                         ├────────────────────────┬───────────────────────┤
                         ▼                        ▼                       ▼
        ┌───────────────────────────────────────────────────────────────────────────────────┐
        │                       Gradient-Based Saliency Engine                              │
        │       abs(d(logit_target) / d(input_signal)) ──▶ (12, 5000) Heatmap               │
        └─────────────────────────────────────────┬─────────────────────────────────────────┘
                                                  │
                         ┌────────────────────────┴───────────────────────┐
                         ▼                                                ▼
        ┌──────────────────────────────────┐             ┌──────────────────────────────────┐
        │      Gradio Web Interface        │             │   Clinical-Grade PDF Engine      │
        │   (Tabs: Test Set / CSV / Batch) │             │   (ReportLab + PyMuPDF Preview)  │
        └──────────────────────────────────┘             └──────────────────────────────────┘
```

## ⚡ Quickstart Guide

### 1. Environment Setup

Clone the repository and install the dependencies:

```bash
git clone https://github.com/MaishaNajAlam/intelligent-ecg-analysis.git
cd intelligent-ecg-analysis

# Create virtual environment
python -m venv venv

# Activate environment
# On Linux/macOS:
source venv/bin/activate

venv\Scripts\activate

# Install requirements
pip install -r requirements.txt
```

> **Note**: HuBERT-ECG requires `git+https://github.com/Edoar-do/HuBERT-ECG.git` (included in `requirements.txt`).

---

### 2. Dataset Setup (PTB-XL)

1. Download the **PTB-XL** dataset (v1.0.3) from PhysioNet:
   - [PhysioNet PTB-XL Download](https://physionet.org/content/ptb-xl/)
2. Extract the dataset into `data/ptbxl/` such that the directory contains:
   ```
   data/ptbxl/
   ├── ptbxl_database.csv
   ├── scp_statements.csv
   ├── records100/
   └── records500/
   ```
3. Run the data validation checkpoint:
   ```bash

   ```
   *This loads a sample record, validates lead channels, outputs `outputs/example_ecg_plot.png`, and verifies diagnosis labels.*

## 💻 Step-by-Step Training & Usage

### Step 1 & 2: Feature Extraction & Encoder

Test the encoder backbone and verify feature shapes:

```bash
python -m src.encoder --test
```
- Backbone: `Edoardo-BS/hubert-ecg-base` (Coppola et al., 2024), pre-trained on 9.1M ECG records.
- Extracts latent representation: `(Batch, 249, 768)` for a 10-second 500 Hz 12-lead signal.
- *Fallback Mechanism*: If offline or loading fails, an internal untrained CNN+Transformer fallback ensures pipeline continuity for development.

---

### Step 3: Train Diagnostic Classifier

Train the 2-layer classification head over cached encoder embeddings:

```bash
python -m src.classifier --train
python -m src.classifier --evaluate
```

- **Classes**: 5 PTB-XL Superclasses
  - `NORM`: Normal ECG
  - `MI`: Myocardial Infarction
  - `STTC`: ST/T Change
  - `CD`: Conduction Disturbance
  - `HYP`: Hypertrophy
- **Loss Function**: Binary Cross-Entropy with Logits (`BCEWithLogitsLoss`) for multi-label classification.
- **Evaluation**: Computes per-class and Macro-AUROC on the official PTB-XL fold 10 test split.
- **Checkpoint**: Saved to `checkpoints/classifier_head.pt`.

---

### Step 4: Train Report Generator

Fine-tune the `FeatureAdapter` and `BART-base` decoder with LoRA:

```bash
python -m src.report_generator --train
python -m src.report_generator --evaluate
```

- **Architecture**: `FeatureAdapter` maps encoder latent vectors (768-dim) into BART cross-attention space.
- **LoRA**: Parameter-Efficient Fine-Tuning applied to BART attention layers (`r=16`, `lora_alpha=32`).
- **Generation**: Autoregressive beam search decoding (`num_beams=4`, `max_length=128`).
- **Evaluation**: Computes BLEU-1 through BLEU-4 and ROUGE-1/2/L metrics; saves `outputs/test_predictions.csv`.
- **Checkpoint**: Saved to `checkpoints/report_generator.pt`.

---

### Step 5: Launch the Interactive Web App

Launch the clinical Gradio web dashboard:

```bash
python -m src.app
```

The application provides:
- **Tab 1: Test-Set Record Explorer**: Select any test record from PTB-XL to visualize all 12 leads with saliency heatmaps, predicted diagnosis, confidence differentials, and AI-generated narrative compared side-by-side with ground-truth reports.
- **Tab 2: Custom CSV Upload**: Upload any custom 12-lead ECG CSV file (`n_samples x 12`) for instant inference and explainability mapping.
- **Tab 3: Batch Analysis**: Process multiple records simultaneously and generate exportable summary tables.
- **Interactive PDF Drawer**: Click **"📄 Preview PDF"** to toggle an instantaneous, high-resolution vector preview of the diagnostic report and download the official PDF.

---

### Step 6: Full Evaluation & Error Analysis

Run systematic performance diagnostics and error profiling:

```bash
python -m src.evaluate_full
```

Generates in `outputs/`:
- `per_diagnosis_performance.csv`: Individual AUROC and metric breakdown across diagnostic superclasses.
- `failure_cases.csv`: Comprehensive catalog of high-confidence failure cases for clinical auditability.
- `evaluation_summary.txt`: Automated diagnostic summary report contrasting rhythm vs. morphology performance.

The PDF export engine (`src/pdf_export.py`) produces hospital-grade diagnostic records:

- **Patient Metadata Grid**: Age, sex, height, weight, recording device, heart axis, and pacemaker status.

- **AI Clinical Narrative**: Full structured medical text covering rhythm, rate, axis, and morphology.

## ⚙️ Configuration Parameters

All pipeline settings can be adjusted in [`src/config.py`](file:///c:/Users/jehad/OneDrive/Desktop/thesis_design_project/intelligent-ecg-analysis/src/config.py):

| Parameter | Default | Description |
|---|---|---|
| `SAMPLING_RATE` | `500` | ECG sampling rate in Hz (500 Hz = 5,000 samples / 10s lead) |
| `PREPROCESSING_MODE` | `"zscore"` | Signal normalization: `"zscore"`, `"minmax"`, or `"bandpass_minmax"` |
| `HUBERT_ECG_MODEL_ID` | `"Edoardo-BS/hubert-ecg-base"` | Foundation model checkpoint on Hugging Face Hub |
| `ENCODER_FEATURE_DIM` | `768` | Latent embedding dimension from encoder |
| `SUPERCLASSES` | `["NORM", "MI", "STTC", "CD", "HYP"]` | Target diagnostic categories |
| `CLASSIFIER_LR` | `1e-3` | Learning rate for MLP classification head |
| `CLASSIFIER_EPOCHS` | `30` | Maximum training epochs for classifier |
| `BART_MODEL_ID` | `"facebook/bart-base"` | Base text generation sequence-to-sequence model |
| `USE_LORA` | `True` | Parameter-efficient fine-tuning for BART decoder |
| `REPORT_GEN_LR` | `5e-5` | Learning rate for adapter and LoRA weights |
| `REPORT_GEN_EPOCHS` | `10` | Maximum training epochs for report generator |
| `REPORT_GEN_NUM_BEAMS` | `4` | Beam width for autoregressive report decoding |

## 🩺 Medical & Diagnostic Reference

| Code | Superclass Name | Clinical Description |
|---|---|---|
| **NORM** | Normal ECG | Regular sinus rhythm without significant electrical or structural abnormalities. |
| **MI** | Myocardial Infarction | Evidence of myocardial necrosis or acute coronary occlusion (Q-waves, ST changes). |
| **STTC** | ST/T Changes | Non-specific or ischemic repolarization abnormalities (T-wave inversion, ST depression). |
| **CD** | Conduction Disturbance | Intraventricular or atrioventricular delays (LBBB, RBBB, LAFB, AV blocks). |
| **HYP** | Hypertrophy | Voltage criteria indicating chamber enlargement (LVH, RVH, atrial enlargement). |

## 🛠️ Troubleshooting & Tips

- **`FileNotFoundError: ptbxl_database.csv`**: Ensure PTB-XL files are placed directly in `data/ptbxl/` and not nested inside subfolders.
- **CUDA Out of Memory (OOM)**: Reduce `REPORT_GEN_BATCH_SIZE` in `src/config.py` (e.g., from `8` to `4` or `2`).
- **HuBERT-ECG Download Issues**: Ensure your Hugging Face Hub connection is active and `trust_remote_code=True` is enabled. The pipeline will automatically fall back to the built-in CNN-Transformer architecture if offline.
- **Local Gradio Access**: To share the web app publicly or access it from Kaggle/Colab, set `share=True` in `src/app.py`.
